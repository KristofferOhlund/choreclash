# Chore Clash - chores made fun

## Installation & setup
1. clone repo, run the command `git clone <url>`
2. run the command `pip install -r requirements.txt`
3. create db schema, run the command `python scripts/ddl.py`
4. Add default chores, run the command `python scripts.dml.py`

## Start server
1. run the command `python main.py`
